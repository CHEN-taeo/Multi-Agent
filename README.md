## Research Directions

- **Agent Collaboration** — Communication protocols, role-based coordination, emergent behaviors
- **Campus AI Applications** — Information filtering, decision support, cognitive coaching
- **Product Design** — From Poke/破壳 ecosystem to standalone multi-agent experiences
- **Socratic AI** — Question-generation agents, bias detection, perspective reframing

## Key Concepts (from brainstorming)

- **破壳雷达 (Campus Bubble Breaker)** — Multi-agent system that filters campus noise into actionable cards
- **苏格拉底提问机 (Socratic Questioner)** — Agent chain that generates better questions instead of summaries
- **认知偏见侦探 (Bias Detector)** — Agent-based cognitive bias identification in consumed content
- **视角万花筒 (Perspective Kaleidoscope)** — Simultaneous multi-role reframing of any topic
